# Example Assets

This directory contains example files for testing the AI-Driven Automated Interviewer.

## Files

- **sample_report.md**: Example output report showing the format and structure
- **sample_screenshot.png**: (To be added - example project screenshot)
- **sample_audio.wav**: (To be added - example audio explanation)

## Usage

1. Use `sample_screenshot.png` to test OCR functionality
2. Use `sample_audio.wav` to test speech-to-text
3. Reference `sample_report.md` to see expected output format

## Creating Your Own Examples

### Screenshot
- Take a screenshot of a project slide, UI, or code
- Save as PNG, JPG, or JPEG
- Ensure text is clear and readable

### Audio
- Record 30+ seconds explaining your project
- Save as WAV format (or MP3/M4A)
- Speak clearly and at moderate pace

### Report
- Reports are automatically generated after completing an interview
- Format includes markdown and PDF versions
